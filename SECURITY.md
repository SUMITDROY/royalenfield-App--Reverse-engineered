# Security reporting

For credential exposure, unauthorized provider access, root command injection or
other exploitable issues, use this repository’s GitHub **Security → Advisories →
Report a vulnerability** if private reporting is enabled. If it is unavailable,
open an issue requesting a private reporting channel without posting exploit
details or secrets. Never publish private device logs or credentials.

Only the current source is maintained; there is no guaranteed support or response
SLA. This experimental root module is not a security boundary against another
root app. Public functional bugs should use the regular issue template.
